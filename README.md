# Jujutsu-Kaisen

React + Vite 기반의 주술회전 팬텀 퍼레이드 팬 사이트입니다. 티어표, 캐릭터 도감, 상세 프로필을 `styled-components`, `react-router-dom`, FSD 스타일 폴더 구조로 구성합니다.

## Start

```bash
npm install
npm run dev
```

## Scripts

```bash
npm run build
npm test
npm run typecheck
```

## Structure

```text
src
├── app
│   ├── providers
│   ├── router
│   └── styles
├── entities
├── features
├── pages
├── shared
└── widgets
```
