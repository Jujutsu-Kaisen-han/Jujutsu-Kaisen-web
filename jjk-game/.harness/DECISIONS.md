## 2026-09-08: 영역 충돌을 50:50 압력 게이지로 전환
- 결정: 양쪽 영역을 합계 100의 게이지로 관리하고, 유효타의 피해량 0.8배만큼 공격자 쪽으로 이동한다.
- 이유: 영역 충돌 중 누가 상대를 때렸는지가 즉시 영역 우세로 보이도록 하기 위해서다.
- 거부된 대안: 충돌 종료 시 누적 피해량만 비교하는 기존 방식은 중간 우세와 완전 밀림을 표시할 수 없어 제거했다.
- 제약: 캐릭터별 영역 상성은 이번 기능 범위에 포함하지 않고, 동률 종료는 양쪽 상쇄로 처리한다.

## 2026-09-08: 고죠 사토루 피해 상향
- 결정: 기본 공격 15, 강공격 32, 핵심 술식 22/32/42/115, 영역 필중 배율 1.2로 조정한다.
- 이유: 고죠가 무하한·육안을 활용하는 고화력 원거리 캐릭터로 체감되도록 하기 위해서다.
- 거부된 대안: 체력이나 무하한 지속시간을 추가 상향하는 방식은 방어 성능까지 과도하게 높일 수 있어 제외했다.
- 제약: 다른 캐릭터의 수치와 기술 쿨다운은 변경하지 않는다.

## 2026-09-21: 전투 모션을 공통 이징 레이어로 개선
- 결정: 이동은 프레임 독립 댐핑, 공격은 anticipation/impact/recovery phase, 대시·착지·피격은 잔상·압축·반동 그래픽으로 표현한다.
- 이유: 공식 공개 무브셋에서 보이는 빠른 진입과 짧은 정지, 강한 방출의 리듬을 기존 Graphics 캐릭터에도 일관되게 적용하기 위해서다.
- 거부된 대안: 외부 영상/이미지 에셋을 그대로 임포트하는 방식은 라이선스·번들 크기·현재 렌더러와의 일관성 때문에 제외했다.
- 제약: 히트박스, 피해량, 쿨다운, 온라인 입력 프로토콜은 변경하지 않고 `BaseCharacter`의 시각 계층과 이동 보간만 수정한다.

## 2026-09-21: 고급 명중 피드백과 idle 생동감 추가
- 결정: 30 이상 피해에는 방사형 스파크·카메라 플래시·확장 충격파를 사용하고, 모든 원거리 투사체에는 별도 글로우 잔상을 붙인다. 옷코츠·고죠·리카는 각자의 idle/공격 움직임을 별도 보간한다.
- 이유: 1차 모션 개선 뒤에도 강한 기술과 평타, 대기 상태의 구분을 더 선명하게 만들어 전투 읽기와 타격감을 높이기 위해서다.
- 거부된 대안: 모든 명중에 강한 플래시와 카메라 효과를 적용하는 방식은 시각 피로와 난전 가독성 저하 때문에 제외했다.
- 제약: 기존 피해량·히트박스·쿨다운·온라인 입력은 유지하고 Phaser Graphics/Tween 레이어만 확장한다.

## 2026-09-28: 선택 화면을 네온 주술 결투 콘솔로 리디자인
- 결정: 외부 에셋 없이 CSS 그리드·광원·글로우·상태별 버튼 스타일로 캐릭터 선택 화면의 계층을 재구성한다.
- 이유: 기존 화면은 READY/START/VS 요소의 시각적 우선순위가 약하고, 선택 상태와 패널 구분이 평평했다.
- 거부된 대안: Phaser 전투 화면이나 캐릭터 로직을 함께 리팩터링하는 방식은 이번 UI 작업의 범위를 벗어나 제외했다.
- 제약: 기존 선택·준비·시작 이벤트, 전투 HUD, 네트워크 흐름은 유지한다.

## 2026-09-28: 전투 HUD와 결과 화면의 정보 계층 강화
- 결정: 전투 HUD는 P1/P2 프레임, 중앙 타이머 플레이트, 스캔라인, 하단 컨트롤 바를 사용하고 결과 화면은 별도 승리 카드로 구성한다.
- 이유: 전투 중 상태 정보가 배경과 섞이지 않고, 라운드 종료 후 다음 행동이 즉시 보이게 하기 위해서다.
- 거부된 대안: HUD 정보를 줄여 화면을 비우는 방식은 조작키와 전투 상태의 접근성을 낮출 수 있어 제외했다.
- 제약: `BattleHudState` 구조와 Phaser 씬 로직은 변경하지 않고 표시 계층만 조정한다.

## 2026-09-28: 솔로 첫 상대와 매치 종료 피드백 정합성 수정
- 결정: 솔로 시작 시 `CHARACTER_ORDER`에서 P1을 제외한 첫 캐릭터를 실제 P2로 전달하고, `matchMessage`를 HUD 중앙 배너에 표시한다.
- 이유: 기존에는 P1이 유지일 때 유지 대 유지로 첫 판이 시작될 수 있었고, 매치 종료 메시지는 상태에만 남아 화면에 보이지 않았다.
- 거부된 대안: 결과 화면으로 즉시 전환해 메시지를 생략하는 방식은 현재 라운드 종료 연출과 중복되고 전투 흐름을 끊을 수 있어 제외했다.
- 제약: 솔로 큐 순서와 결과 화면 전환 시점, 전투 판정은 유지한다.

## 2026-09-28: 선택 캐릭터 전투 리드아웃 추가
- 결정: 선택 카드 아래에 현재 캐릭터의 전투 성향과 임팩트·기동성·주력 보유량을 보조 막대로 표시한다.
- 이유: 이름과 타이틀만으로는 캐릭터 선택 차이가 즉시 읽히지 않아, 시작 전에 플레이 스타일을 판단할 수 있게 하기 위해서다.
- 거부된 대안: 카드마다 모든 기술 설명을 펼치는 방식은 선택 화면을 과밀하게 만들 수 있어 제외했다.
- 제약: 실제 스탯 값과 전투 로직은 변경하지 않고 기존 캐릭터 정의에서 표시용 값만 계산한다.
