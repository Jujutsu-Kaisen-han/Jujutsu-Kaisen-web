# 계획 0006: 전투 HUD 및 결과 화면 폴리시

> 생성일: 2026-09-28 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 전투 HUD의 P1/P2 상태판, 중앙 라운드 타이머, 조작 안내를 선택 화면과 같은 시각 언어로 정리한다.
- 결과 화면에 승리 상태의 계층과 재시작 CTA를 보강한다.
- HUD 정보 구조와 전투 입력/상태 업데이트 로직은 유지한다.

## 제외 (이번에 안 할 것)
- Phaser 전투 렌더링, 공격 판정, 데미지, 밸런스 변경
- 네트워크 매칭과 라운드 진행 로직 변경
- 새 이미지·폰트·패키지 추가

## 완료 정의 (실행 가능한 조건)
- [ ] HUD에서 양쪽 체력/에너지/궁극기/영역 상태가 명확히 구분된다.
- [ ] 중앙 타이머와 하단 조작 안내가 게임 화면을 가리지 않으면서 읽기 쉽다.
- [ ] 결과 화면의 승리 메시지와 CTA가 일관된 스타일을 가진다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 게임 테스트가 통과한다.

## 메모 / 결정
- 기존 HUD 데이터와 CSS 클래스 호환성을 유지한 채 시각적 계층만 개선한다.
