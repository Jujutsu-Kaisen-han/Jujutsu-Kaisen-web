# 계획 0004: 고급 타격 피드백과 시그니처 idle 모션 추가

> 생성일: 2026-09-21 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 강공격·고위력 기술의 명중 순간에 충격파, 방사형 스파크, 짧은 카메라 펀치를 추가한다.
- 원거리 술식 투사체에 코어·글로우·후방 잔상을 추가하고 같은 이동 보간을 공유한다.
- 옷코츠의 검 대기 모션과 고죠의 무하한 대기 파동을 미세하게 애니메이션한다.
- 리카의 공격에 짧은 전진 런지와 회수 모션을 추가한다.

## 제외 (이번에 안 할 것)
- 피해량·히트박스·쿨다운·이동 속도 수치 변경
- 신규 외부 아트 에셋 또는 저작물 복제
- 온라인 입력 동기화 프로토콜 변경

## 완료 정의 (실행 가능한 조건)
- [x] 강타와 기술 명중 연출이 일반 명중과 시각적으로 구분된다.
- [x] 원거리 투사체가 이동 중 잔상을 남기고 종료 시 정상적으로 정리된다.
- [x] 옷코츠·고죠·리카의 idle/공격 시그니처 모션이 프레임 보간된다.
- [x] `npm run lint --if-present` 통과
