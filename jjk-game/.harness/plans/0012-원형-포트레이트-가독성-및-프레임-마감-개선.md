# 계획 0012: 원형 포트레이트 가독성 및 프레임 마감 개선

> 생성일: 2026-09-29 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 포트레이트를 원형 본체의 중심에 맞추고 이미지 위에 이름표가 겹치지 않게 배치한다.
- 이미지가 있을 때도 원형 색상 프레임·하이라이트·슬롯 표시가 선명하게 남도록 시각 레이어를 정리한다.
- 이미지 로딩 실패 fallback과 기존 전투 이펙트를 유지한다.

## 제외 (이번에 안 할 것)
- 새 캐릭터 추가 및 전투 규칙 변경

## 완료 정의 (실행 가능한 조건)
- [ ] 포트레이트가 이름표와 겹치지 않고 원형 프레임 안에서 표시된다.
- [ ] 포트레이트 캐릭터의 기존 공격·영역·피격 이펙트가 유지된다.
- [ ] `npm run lint --if-present && npm run build && npm test && harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 검증 통과 및 F12 passing

## 메모 / 결정
- 초상화는 원형 프레임보다 살짝 작게 두고 색상 프레임을 별도 레이어로 남겨 실루엣 대비를 확보한다.
