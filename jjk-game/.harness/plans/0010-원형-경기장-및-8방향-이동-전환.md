# 계획 0010: 원형 경기장 및 8방향 이동 전환

> 생성일: 2026-09-29 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 경기장을 직사각형 바닥/벽에서 중앙 원형 전장과 동심 링으로 변경한다.
- P1/P2 입력에 상하 방향을 추가하고 WASD/방향키로 8방향 이동이 가능하게 한다.
- 중력·점프 기반 이동을 제거하고 원형 경계 반경 안으로 캐릭터를 제한한다.
- 이동 벡터를 기준으로 대시, 캐릭터 충돌, 근접 공격 판정이 동작하도록 조정한다.
- 원형 전장에 맞춰 영역전개/영역충돌/유타 검 위치와 AI 이동을 함께 보정한다.

## 제외 (이번에 안 할 것)
- 캐릭터 밸런스, 기술 피해량, 쿨다운 변경
- 온라인 매칭 서버 프로토콜 변경
- 기술 VFX 신규 제작 (현재 진행 중이던 미완성 계획은 폐기)

## 완료 정의 (실행 가능한 조건)
- [ ] 경기장이 원형으로 보이고 캐릭터가 원 바깥으로 나가지 않는다.
- [ ] WASD/방향키의 상하좌우 및 대각선 입력이 모두 이동에 반영된다.
- [ ] 근접 공격과 AI가 세로 거리/8방향 위치를 고려한다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 전투 테스트가 통과한다.

## 메모 / 결정
- 캐릭터 그래픽의 기준점은 기존 하단 기준 좌표를 유지해 스프라이트를 전면 재작성하지 않고 이동 좌표계만 원형으로 전환한다.
