# 계획 0008: 선택 캐릭터 전투 리드아웃 추가

> 생성일: 2026-09-28 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- P1/P2 선택 패널에 현재 선택 캐릭터의 전투 성향과 핵심 스탯 리드아웃을 추가한다.
- 임팩트·기동성·주력 보유량을 일관된 막대 그래프로 표현한다.
- 기존 선택 카드와 시작/준비 이벤트는 변경하지 않는다.

## 제외 (이번에 안 할 것)
- 캐릭터 스탯 수치, 밸런스, 기술 판정 변경
- 전투 HUD 및 Phaser 렌더링 변경
- 외부 에셋·패키지 추가

## 완료 정의 (실행 가능한 조건)
- [ ] P1/P2의 현재 선택 캐릭터 정보가 선택 패널 안에서 즉시 보인다.
- [ ] 리드아웃이 데스크톱/모바일에서 패널을 깨뜨리지 않는다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 테스트가 통과한다.

## 메모 / 결정
- 카드 목록은 빠른 선택용으로 유지하고, 리드아웃은 선택된 캐릭터의 판단을 돕는 보조 정보로만 사용한다.
