# 계획 0007: 솔로 첫 상대 및 매치 종료 피드백 수정

> 생성일: 2026-09-28 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 솔로 모드 시작 시 선택한 캐릭터와 다른 첫 상대를 큐에서 정확히 선택한다.
- 매치 종료 직전 Battle HUD에 매치 승리 메시지를 표시한다.
- 기존 솔로 진행, 로컬/온라인 선택, 결과 화면 동작은 유지한다.

## 제외 (이번에 안 할 것)
- 캐릭터 밸런스 및 전투 판정 변경
- 매칭 서버 프로토콜 변경
- HUD의 전면 리디자인

## 완료 정의 (실행 가능한 조건)
- [ ] 솔로에서 어떤 캐릭터를 골라도 첫 상대가 자기 자신이 아니다.
- [ ] 매치 종료 시 승리 메시지가 HUD에 표시된다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 테스트가 통과한다.

## 메모 / 결정
- 솔로 첫 상대는 `CHARACTER_ORDER`에서 플레이어 캐릭터를 제외한 첫 항목으로 계산해 큐와 실제 전투 선택을 동일하게 유지한다.
