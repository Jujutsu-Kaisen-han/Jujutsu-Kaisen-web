# 계획 0009: 준비 상태 기반 시작 CTA 개선

> 생성일: 2026-09-28 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 시작 CTA에 현재 준비 인원과 필요한 준비 인원을 표시한다.
- 준비가 모두 끝나면 CTA가 `START DUEL`로 전환되고 기존 클릭 동작을 유지한다.
- 솔로/온라인은 1인 준비, 로컬은 2인 준비 기준을 사용한다.

## 제외 (이번에 안 할 것)
- 준비 상태 저장 및 네트워크 동기화 변경
- 캐릭터 카드/전투 시스템 변경
- 새로운 에셋·패키지 추가

## 완료 정의 (실행 가능한 조건)
- [ ] 준비 전 CTA가 현재 상태를 `READY CHECK // 현재 / 필요` 형태로 표시한다.
- [ ] 준비 완료 시 CTA가 `START DUEL`로 표시된다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 테스트가 통과한다.

## 메모 / 결정
- CTA 문구만 상태에 따라 바꾸고 `disabled`와 `onStart`의 기존 계약은 그대로 유지한다.
