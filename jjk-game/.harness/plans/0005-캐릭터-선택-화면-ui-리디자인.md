# 계획 0005: 캐릭터 선택 화면 UI 리디자인

> 생성일: 2026-09-28 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 캐릭터 선택 화면의 색상 토큰, 배경 레이어, 패널 계층, 버튼 상태를 재설계한다.
- P1/P2 선택 카드와 READY 상태가 즉시 구분되도록 선택 강조, 포커스, 호버, 상태 배지를 보강한다.
- 모드 탭, VS 마크, START DUEL CTA, 모바일 레이아웃을 완성한다.
- 기존 캐릭터 선택/준비/시작 동작과 전투 화면 로직은 유지한다.

## 제외 (이번에 안 할 것)
- Phaser 전투 시스템 및 캐릭터 밸런스 변경
- 새로운 외부 이미지·폰트·패키지 추가
- 온라인 매칭 프로토콜 변경

## 완료 정의 (실행 가능한 조건)
- [ ] 선택 화면이 데스크톱/모바일에서 계층적으로 보이고 주요 CTA가 명확하다.
- [ ] 선택/READY/비활성/호버 상태가 스타일로 구분된다.
- [ ] `npm run lint --if-present` 통과
- [ ] `npm run build` 통과
- [ ] `npm test` 통과
- [ ] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present && npm run build && npm test && harness check`
- 기대 결과: 모든 명령이 오류 없이 종료되고 기존 게임 동작 테스트가 통과한다.

## 메모 / 결정
- 별도 에셋 없이 CSS 그리드, 글로우, 노이즈/스캔라인 레이어로 완성도를 높인다.
