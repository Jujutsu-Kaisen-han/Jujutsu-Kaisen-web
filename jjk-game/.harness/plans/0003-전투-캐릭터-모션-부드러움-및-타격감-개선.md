# 계획 0003: 전투 캐릭터 모션 부드러움 및 타격감 개선

> 생성일: 2026-09-21 | 단계: plan → construct → test

## 범위 (이번에 할 것)
- 캐릭터 이동에 가속·감속 관성을 넣어 방향 전환과 정지가 끊기지 않게 한다.
- 대시·착지·공격·피격 상태를 공통 모션 레이어로 보간한다.
- 공격에 anticipation → impact → recovery 타이밍과 무기/술식 잔상을 추가한다.
- 옷코츠는 검격·리카 에너지, 고죠는 무하한의 파동·압축/방출 실루엣이 느껴지도록 시그니처 모션을 강화한다.
- 프레임 기반 이징 함수를 순수 모듈로 분리해 경계값을 자동 테스트한다.

## 제외 (이번에 안 할 것)
- 피해량·히트박스·쿨다운 밸런스 변경
- 신규 외부 아트 에셋 또는 저작물 복제
- 온라인 입력 동기화 프로토콜 변경

## 완료 정의 (실행 가능한 조건)
- [x] 전투 중 이동·대시·공격·피격·착지가 프레임 보간으로 자연스럽게 이어진다.
- [x] 옷코츠와 고죠의 공격 모션이 기존 공통 모션과 시각적으로 구분된다.
- [x] `npm run lint --if-present` 통과
- [x] `npm run build` 통과
- [x] `npm test` 통과
- [x] `harness check` 통과

## 검증 방법
- 명령: `npm run lint --if-present`, `npm run build`, `npm test`, `harness check`
- 기대 결과: 모든 명령이 종료 코드 0이며 모션 이징 테스트와 기존 전투 테스트가 모두 통과한다.

## 메모 / 결정
- 공식 Cursed Clash 소개와 Yuta 무브셋/극장판 공식 트레일러에서 보이는 빠른 진입, 짧은 정지, 강한 방출의 리듬을 참고하되 외부 영상을 코드나 에셋으로 복제하지 않는다.
- 전투 판정 시간은 유지하고 시각적 변형과 이동 관성만 조정해 밸런스 회귀를 막는다.
